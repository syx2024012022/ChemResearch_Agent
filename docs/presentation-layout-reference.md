# 有机化学组会 PPT 版式参考总结

本规范来自桌面 `ppt版式参考` 文件夹中的 11 张用户认可截图。它们作为一套风格样本使用，而不是 11 个彼此独立的固定模板。Composer 应根据来源图形的方向、数量和叙事关系选择版式。

## 整体风格

页面以白底为主，保留明确但克制的英文标题。视觉主体不是装饰图，而是论文中的反应式、化学结构、机理、底物范围、优化表和数据图。页面可以较满，因为听众具有化学专业背景，但必须靠标题、面板标签、分隔线和稳定的颜色语义建立层级。

使用课题组标准模板时，标题落在页面顶部的深蓝横幅内，因此标题必须使用白色字体并居中。黑色或深色标题只适用于标题实际位于白色内容区的其他模板；标题颜色应由模板背景决定，而不是由 Composer 随意选择。

可见文字默认使用英文。标题可采用 `Proposed mechanism`、`Reaction optimization and substrate scope` 一类简短名词短语。除非用户明确要求中文或双语，否则不把中文作为专业组会的默认输出语言。

字体规范：英文使用 Arial，中文使用黑体（`SimHei`）。中英混排必须按字符片段分别应用字体；论文 Figure 内部原有字体属于来源图片，不进行替换或重绘。

## 按图形方向选择版式

### 多面板整图（A–D / A–E 等）

一个来源图片中已经组合了多个有明确面板标记的实验、结构、谱图或机理时，它本身就是一套完整视觉叙事，不按普通“单张图”处理。保留原始面板顺序和相对位置，不在旁边重复加入正文说明；裁去外围白边后，按高度放大至标题栏下方可用区域的约 95%，左右居中。只有面板标签或关键内容确实无法阅读时才考虑拆页，不能为了填满宽度而拉伸变形。

“占满”以有效图形在页面上的体感面积判断，而不是以图片容器尺寸判断。对于无需侧栏说明的单图或多面板整图，图片可以紧贴白色区域的上下边界；如果有效内容仍只集中在页面中央，应继续安全裁白边、放大，或按原有面板边界重新组合。

机理、光物理/表征证据与底物范围/拓展应用承担不同叙事任务。只要各自素材足够，就分别成页，不为了追求较少页数把它们缩小后并排。两个图确实需要并排时统一视觉高度，并依据证据重要性分配宽度，例如让 Hammett 拟合图适当大于常规反应示意。

### 横向图或长反应路线

横向图最适合标题下全宽展示，占可用画布约 70%–85%。长反应路线、催化循环展开图和多步机理应沿其自然方向铺开，不在两侧硬塞成段文字。最多加入一行 takeaway，或在对应步骤附近加入很短的彩色标签。

若有两张横向图：

- 有先后关系时采用上下两带，使用细灰线或虚线分隔。
- 是条件或方法对照时采用左右并列，并保持两侧反应箭头、结构尺度和标签位置一致。
- 一张明显更重要时采用主图约 65%、辅图约 35% 的主次布局。

若单张图即使裁掉外围白边后仍无法自然铺满全宽，应避免把它居中后在两侧留下等量空白。默认将图向右移动并占据约 60%–65% 的页面宽度；左侧使用论文正文中与该图直接对应的 1–2 条简短描述。文字可放在浅灰色圆形区域内，以平衡构图并强调本页逻辑。圆形不得遮挡图，也不应成为与内容无关的装饰。

### 纵向图

纵向图不应被拉宽或孤零零缩在页面中央。优先顺序是：

1. 两张相关纵图左右并列；
2. 单张纵图占左侧或右侧约 55%–65%，另一侧放 2–3 条与图中位置对应的短逻辑；
3. 若来源图存在可靠的面板边界，可按面板拆开后重新组合；不得切断结构、箭头、坐标轴或图例。

### 多个小图、底物矩阵或表格

总反应与关键条件放在顶部 20%–30%，底物矩阵占下部 60%–75%。结构网格要尽量维持原图的行列秩序。只对少数重要样例使用细框或来源标签，不给每个结构附加长句。

优化表和实验对照适合左右并排；每张表的上方放与其对应的反应式，避免读者跨越页面寻找条件属于哪项实验。

## 按叙事任务选择版式

### 背景与研究空白

采用两栏或多栏结构对比，中间以极短的 `Gap`、`Uncharted space` 或箭头连接。左右主要展示代表性结构或已知反应，文字只说明各自能做什么以及缺少什么。

### Previous work 与 This work

优先上下对照：上方放已有方法和红色局限，下方放本文方案和绿色优势。反应图必须大于评价文字。颜色表达“问题/改进”的逻辑，不承担装饰功能。

### 机理研究与拟议机理

证据页可由谱图、控制实验、计算或表格组成多个面板，并在最靠近证据的位置放一条推断。拟议机理页应让路径横贯整页；双路径采用上下排列。步骤名、中间体名和关键条件可用蓝、橙或黄色作少量区分。

### 总结

继续使用代表性反应、机制主线或 TOC Graphic 作为视觉主体，用 2–3 个极短结论回扣贡献。禁止切换成纯文字 bullet 总结页。

## 文字如何嵌入图中

- 一条文字只回答一个问题：这是什么、为什么重要，或它证明了什么。
- 文字应靠近其证据：条件贴近箭头，结论贴近对应图或结构，局限贴近发生问题的反应。
- 不把标题换一种说法后再写成长段正文。
- 颜色语义保持稳定：深蓝为条件和标签，紫色为分区，绿色为优势或有效结果，红色为问题或局限，浅蓝框为关键产物/中间体。
- 当信息放不下时，先删减次要文字、拆分叙事或换版式，不缩小到难以阅读。

## Composer 的选择规则

Composer 在排版前应先判断：图的横纵比、可安全裁切的面板边界、图的数量、图之间是先后/对照/证据关系，以及本页唯一的核心信息。随后从“全宽横图、双图对照、纵图加侧注、上反应下 scope、优化并排、主题侧栏加反应带、全宽机理”中选择版式。若任何版式都无法在不破坏化学信息的前提下容纳内容，应拆页而不是强塞。
